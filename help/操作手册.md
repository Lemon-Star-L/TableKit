## 一、启动与准备

### 1.1 直接打开工作台

解压项目后，使用桌面版 Chrome 或 Edge 普通窗口打开 `output/表格数据处理工作台.html`。日常使用不需要安装或运行 Python，也不需要联网。

如需根据模板重新生成页面，在项目根目录执行：

```bash
python main.py
```

构建环境要求为 Python 3.13+，仅使用 Python 标准库。使用 uv 时可执行 `uv run main.py`。页面打开后可关闭 Python，浏览器中的操作仍可继续。

### 1.2 准备业务文件

建议使用一行字段名、下方连续排列明细记录的表格。文件可以放在电脑任意目录，无需复制到项目内。

- 件号、编码等需要保留前导零的字段，应在源文件中存为文本。
- 数量、方量等参与计算的字段，应保持数值口径一致。
- 日期需要排序时，建议统一为 `YYYY-MM-DD`；带时间时统一为 `YYYY-MM-DD HH:mm:ss`。
- 多表汇总前，应统一公共字段名称及含义。

## 二、界面与数据存储

| 区域 | 主要用途 |
| --- | --- |
| 顶部统计卡片 | 查看已载入表单数量、总行数及当前表规模；总行数包含生成的结果表 |
| 文件导入 | 选择文件、读取表单并设置导入参数 |
| 数据工作区 | 切换当前表，进行筛选、排序、去重、透视和字段合并与重复汇总 |
| 数据预览 | 分页查看当前表，或导出当前完整表 |
| 底部状态提示 | 查看进度、执行结果和错误信息 |
| 侧栏撤销与清理入口 | 撤销最近操作，或清空浏览器中的工作区数据 |

**工作区表单、HTML 文件和导出文件是三个不同对象。** 导入表、去重表、透视表和字段合并结果保存在浏览器本地数据库中，不会自动写入 HTML，也不会自动生成电脑上的文件。需要长期保存或交付时，应执行导出。

同一工作区建议仅在一个标签页内操作。文件处理期间不要关闭页面。

## 三、导入文件

### 3.1 操作步骤

1. 点击“选择文件”，或将文件拖入上传区域。
2. 点击“读取表单”。
3. 展开“导入设置与表单选择”，确认参数并勾选所需工作表。
4. 点击“导入所选表单”。
5. 等待状态提示完成，在“数据工作区”的下拉列表中选择需要处理的表。

未读取表单时直接导入，会导入该文件的全部可用表单；读取表单后，至少需要勾选一项。多选区域提供“全选”“清空”和已选数量，无需按住 Ctrl。

### 3.2 参数说明

| 参数 | 设置方法 |
| --- | --- |
| 表头行 | 按源文件中的实际行号填写，从 1 开始；表头之前的内容不作为明细导入 |
| CSV 编码 | 默认 `utf-8-sig`；其他选项包括 `gb18030`、`utf-16`、`big5`，应与文件实际编码一致 |
| 分隔符 | 默认 CSV 使用逗号、TSV 使用制表符；也可指定逗号、制表符、分号或竖线。TXT 需按实际内容选择 |
| Excel 公式 | 可读取“上次保存的计算值”或“公式文本”；工作台不重新计算公式 |
| 工作表 | 可选择一个或多个表单，隐藏工作表也可选择 |

### 3.3 导入规则

支持 XLSX、XLSM、XLS、XLSB、CSV、TSV、TXT。全空白记录会跳过；空白字段名会自动补名，重复字段名会添加后缀区分。

Excel 的样式、合并结构和宏不会保留。公式没有已保存计算值时，导入结果可能为空；可先在 Excel 中重新计算并保存，或改为读取公式文本。Excel 日期值转为日期文本，CSV 中的日期文本不会自动统一格式。

重复导入同一文件会新增工作区表，不会自动替换原表。

## 四、预览、筛选与排序

### 4.1 选择当前表与显示字段

在“数据工作区”下拉列表中选择目标表，切换到“预览 · 筛选 · 排序”。展开“显示 / 导出字段”，勾选需要的字段，再点击“应用并预览”。至少保留一个显示字段。

切换当前表会重置该视图的筛选、排序和字段选择。可通过“上一页”“下一页”或页码跳转浏览数据；预览行数不代表全部结果行数。

### 4.2 设置筛选

点击“＋ 条件”，依次设置字段、运算符、比较值和比较类型。在条件组合菜单选择 AND（全部满足）或 OR（任意满足）；该设置同时用于预览、统计、筛选导出及按条件删除。

| 目的 | 示例设置 |
| --- | --- |
| 查找特定仓库 | 仓库 → 等于 → 重庆中心库 → 文本 |
| 保留正数量记录 | 数量 → 大于 → 0 → 数值 |
| 查询件号片段 | 件号 → 包含 → 00012 → 文本 |
| 检查缺失值 | 数量 → 为空；无需填写比较值 |

数量、方量等大小比较应选择“数值”；件号、仓库名称等选择“文本”。“包含”“不包含”按文本匹配。文本比较区分大小写，“为空”识别缺失值、空字符串、纯空格、全角空格、不间断空格和常见零宽字符；0 不属于空白。

配置完成后点击“应用并预览”。需要准确行数时，点击“统计筛选行数”；需要恢复全部记录时，点击“清空筛选与排序”。

### 4.3 设置复合排序

点击“＋ 排序字段”，设置字段、升序/降序及文本/数值类型。多个排序字段按界面从上到下的顺序确定优先级。

例如，先按“仓库”文本升序，再按“数量”数值降序，可在每个仓库内将数量较大的记录排在前面。无效数值排在末尾。日期采用文本排序，应先统一日期格式。

排序只改变当前查看及筛选结果导出的顺序，不改变去重操作认定的原始导入顺序。


### 4.4 计算错误与空结果

筛选运算符提供“计算错误”“计算错误或结果为空”。后者匹配错误标记或空值；比较值与文本/数值类型不参与判断，界面自动禁用。也可选择“为空”单独检查空结果。支持预览、统计、筛选导出、删除及批量清洗，仍按 AND/OR 组合条件。

可识别常见 Excel 错误标记，如 `#DIV/0!`、`#VALUE!`、`#REF!`、`#N/A`、`#NAME?`、`#NUM!`、`#SPILL!`、`#CALC!`。按整个单元格值匹配，前后空格忽略，包含错误字样的一段普通说明不会被误判。

判断依据是导入后的值，不重新计算公式，也不区分原生错误与相同内容的文本。请在导入设置中选择“读取上次保存的计算值”，并先用 Excel 重算、保存。无缓存公式与真正空结果可能都导入为空；普通空单元格也会匹配“结果为空”。如选择“读取公式文本”，不能据此判断公式运行结果。旧缓存若没有保留错误标记，需要重新导入源文件。

点击工作区“预览 · 筛选 · 排序”“去除重复”“动态数据透视”时，左侧对应导航自动高亮；点击左侧导航也同步切换工作区。点击导入区域时，高亮回到“文件导入”。

## 五、删除、编辑与新增行

### 5.1 按条件删除

1. 选择当前表，在“预览 · 筛选 · 排序”设置一个或多个条件。
2. 选择 AND 或 OR；先“应用并预览”并“统计筛选行数”，核对待删除范围。
3. 点击“删除符合条件的行”，确认后处理整张表的全部匹配记录。修改条件后应重新核对；删除使用按钮点击时的当前条件。
4. 页面切换至“原表名_清洗”结果表。来源表仍保留，可通过“撤销”移除本次结果。

必须至少设置一个条件。删除不限当前分页，也不受显示字段选择影响。删除全部匹配行后允许生成只含字段的空表。

### 5.2 删除勾选行

在预览左侧勾选记录，或勾选表头复选框选中本页，点击“删除勾选行”。勾选不会跨页保留；翻页、排序或刷新预览后需重新选择。程序使用记录标识定位，不以页面序号定位，排序不会删错行。

### 5.3 编辑与新增

点击记录旁的“编辑”，在弹窗中修改字段，选择“保存并生成新表”；隐藏字段也会显示在编辑弹窗中。取消不会写入数据。点击“新增行”填写全部所需字段，新行追加到新结果表末尾。

输入内容按文本保存，留空保存为空值；不会自动计算公式或推断日期。编辑、新增均保留来源表，并切换到无筛选的新结果表，便于核对。若要连续修改，请继续操作最新结果表；大表生成副本需要时间和额外缓存空间。

### 5.4 多表批量清洗

展开“多表批量清洗”，勾选来源表，复用上方筛选条件后执行。字段按名称匹配，字段顺序可以不同；任何指定字段缺失均跳过该表，即使采用 OR 逻辑也不部分执行。建议一次选择同一工作簿的全部来源，避免把旧结果重复纳入。

运行中显示总扫描进度，结束显示逐表原行数、删除量、保留量、跳过原因及合计。点击“导出本次清洗工作簿”可将本次结果及跳过的原表合并保存；工作表名自动处理禁用字符、长度和重名。报告关联本次页面会话，刷新后可从表单列表找到结果并逐表导出。

批量导出为 XLSX，在内存中生成，每张表最多 1,048,575 行明细。超过上限时请分别导出 CSV/TSV/JSON。浏览器支持时使用保存对话框，否则提供下载链接；文件已存在时按浏览器提示处理，建议使用新名称。

### 5.5 保留格式清洗

仅当需要保留原 Excel 格式时使用 Python 可选模式：

```bash
python -m pip install "openpyxl>=3.1.5,<4"
python main.py --clean-excel "业务.xlsx" --rules "test/清洗规则示例.json"
```

规则示例（满足任意条件即删除）：

```json
{
  "logic": "OR",
  "rules": [
    {"field": "仓库", "op": "contains", "value": "测试"},
    {"field": "件号", "op": "empty"}
  ]
}
```

`op` 可选 `contains`（包含）、`=`（完全匹配）、`empty`（空白）；`logic` 可选 AND 或 OR。第一行识别字段，重复表头采用最左列。全部工作表参与检查，缺字段的表保留并记录。输出采用新名称，已存在时自动编号，旁边生成 JSON 统计报告。

普通单元格格式、超链接、批注、行高及隐藏状态随保留记录复制，公式相对引用尝试随移动调整。程序不会重算公式；无缓存公式不直接当作空白，报告显示不确定检查次数。公式返回空字符串与缺失缓存可能无法可靠区分，请先重算保存并核对。复杂合并、外部链接、图表、透视表及跨行公式依赖需用副本验收，不能视为完整 Excel 编辑器。

### 5.6 修改操作验收

- 导入 `01_去重筛选样例.csv`，按“数量数值等于 0”删除，应由 6 行变为 5 行；撤销后回到 6 行来源表。
- 按数量降序预览，编辑某条记录的备注，检查编号仍对应原记录，来源表不变。
- 新增一行后总行数加 1；撤销后回到新增前的表。
- 选择字段不同的多张表批量清洗，核对缺字段的表显示跳过且导出时保留。
- 分别检查文件选择、取消编辑、取消保存、保存 XLSX、刷新后逐表导出及缓存清理。

## 六、重复记录处理

### 6.1 操作步骤

1. 选择需要去重的来源表，进入“去除重复”。
2. 选择判重方式并勾选字段。
3. 选择保留规则，按需填写新表名称。
4. 确认是否勾选“仅处理当前筛选范围”。
5. 点击“执行去重并生成新表”。
6. 核对处理、删除和保留行数，再点击“导出去重结果”保存。

### 6.2 判重与保留规则

| 设置 | 含义 |
| --- | --- |
| 按选中字段判重 | 所选字段的组合值相同即视为重复；至少选择一个字段 |
| 除选中字段外，按其余全部字段判重 | 勾选不参与判重的字段；剩余字段用于比较，至少保留一个判重字段 |
| 保留源数据第一行 | 每个重复组保留最先导入的一行 |
| 保留源数据最后一行 | 每个重复组保留最后导入的一行 |
| 删除全部重复组，只保留唯一行 | 重复组内所有记录都删除，仅保留出现一次的组合 |

若仅“序号”不同、其余内容一致，可选“除选中字段外……”并勾选“序号”。若只判断件号是否重复，可选“按选中字段判重”并勾选“件号”。

判重不自动去空格或忽略大小写，`01` 与 `1` 不视为相同。空值在判重时视为相同。

### 6.3 结果范围

不勾选“仅处理当前筛选范围”时处理整张来源表；勾选后，新表仅包含筛选范围内的去重结果，范围外记录不会追加到新表。来源表始终保留。

生成后工作区会切换到新表。再次执行去重前，应确认当前表，避免误将上一次结果作为本次来源。

## 七、单表与多表透视

### 7.1 操作步骤

1. 进入“动态数据透视”，勾选一个或多个来源表。
2. 检查公共字段数量，选择行字段、列字段和汇总指标。
3. 按需设置筛选范围、无效值处理及结果名称。
4. 点击“生成 / 重新计算透视表”。
5. 检查结果，并通过“导出透视结果”保存。

| 配置 | 用途 |
| --- | --- |
| 行字段 | 定义分组维度，例如仓库、模块；不选且不设列字段时整体汇总 |
| 列字段 | 将组合值展开为结果列，例如按日期展开；不选则普通分组汇总 |
| 值字段 | 选择数量、方量或其他待统计字段；“记录行数”不依赖值字段 |
| 汇总方式 | 求和、平均值、最小值、最大值、记录行数、值字段非空计数、值字段去重计数 |
| 对每个来源应用工作区当前筛选 | 将当前筛选条件分别应用到每张来源表；条件涉及的字段必须在各来源中存在 |
| 忽略无效数值 | 数值汇总遇到非空非数值时跳过该值；未勾选时停止并提示 |

行字段与列字段不能重叠。空值不参与数值汇总；“记录行数”统计所有符合条件的记录，“非空计数”与“去重计数”不计空值。

### 7.2 多表处理口径

多表透视按照同名公共字段纵向追加，再进行分组汇总，不是按件号等主键进行表间关联。重复记录仍参与汇总。

不要同时勾选同一批业务的原始表和它的去重结果，否则同一业务可能重复计入。更改配置后重新计算会生成另一张结果表，不覆盖先前结果。

### 7.3 常用配置

- **按仓库统计数量：** 行字段选“仓库”，不选列字段，值字段选“数量”，汇总方式选“求和”。
- **按仓库和模块统计：** 行字段选“仓库”“模块”，不选列字段，值字段选“数量”，汇总方式选“求和”。
- **按日期横向展开：** 行字段选“仓库”，列字段选“日期”，值字段选“数量”，汇总方式选“求和”。

## 八、字段合并与重复汇总

本模块用于将不同 Excel 文件或不同 Sheet 的明细统一字段后，按用户指定的分组字段汇集明细，并汇总数量、方量等数值字段。它不会修改来源工作簿，也不替代原有“去除重复”和“动态数据透视”。

### 8.1 选择数据来源

1. 在左侧导航点击“字段合并”。
2. 点击“选择多个 Excel 文件”，可一次选择多个 XLSX、XLSM、XLS 或 XLSB 文件。
3. 点击“选择文件夹”，优先使用浏览器目录授权递归读取文件夹内的 Excel 文件；若浏览器不支持该接口，则使用文件夹选择兼容入口。
4. 选择文件或文件夹后，系统自动逐个读取文件的 Sheet 列表。默认表头行为第 1 行；可在来源区域上方设置“默认表头行”，选择文件前设置会应用于新加入的 Sheet，选择文件后点击“应用到全部 Sheet”可统一调整。
5. 在来源列表中勾选实际需要的 Sheet；可使用“全选 Sheet”“清空 Sheet 选择”快捷调整。来源清单中“表头行”列可以逐个设置每个 Sheet 的实际表头所在行，修改后系统会重新识别字段。

注意：文件夹选择会读取目录中的 Excel 文件，不会读取 CSV、TXT 等格式。若文件中有标题行、说明行或表头不在第一行，请调整对应 Sheet 的“表头行”。表头识别失败的 Sheet 需要修正表头行或取消勾选。

### 8.2 字段识别与手动映射

系统将字段名称首尾空格去除后进行完全匹配，名称相同的字段自动对应。不会根据“零件编号”和“货品编码”等词义相近关系自动猜测。

在字段映射表中，每个来源字段均可选择：

- **已有标准字段：** 将不同来源字段统一到同一个输出字段。例如“零件编号”映射到“货品编码”。
- **新增标准字段：** 在映射区输入新的标准字段名称并点击“新增标准字段”，再将来源字段映射到该字段。未映射来源的自定义标准字段会按缺失字段规则逐项确认。
- **忽略此来源字段：** 当前来源字段不进入标准字段，也不参与分组或求和。

同一个 Sheet 内，不允许两个来源字段映射到同一个标准字段，以免发生字段覆盖。若字段映射关系需要反复使用，可输入模板名称并保存；模板仅保存在当前浏览器，不会随 HTML 自动转移到其他电脑。应用模板后仍应逐项核对映射结果。

### 8.3 缺失字段处理

当某个 Sheet 缺少当前标准字段时，系统会弹出确认窗口，显示来源文件、Sheet 和缺失字段。每个缺失字段需要单独选择：

1. **当前缺少字段补充为空白，继续处理：** 该 Sheet 对应字段按空值处理。若该字段是求和字段，空值按 0 计算。
2. **跳过当前 Sheet：** 仅当前工作表不参与本次合并，同一文件中的其他已选 Sheet 仍可继续处理。
3. **跳过当前文件：** 当前文件中其他已选 Sheet 一并跳过，后续文件仍可继续处理。
4. **取消整个合并任务：** 终止本次任务，不生成合并结果。

如果选择跳过当前 Sheet 或当前文件，则被跳过范围内的其他缺失字段不再逐项询问，因为相关工作表已不参与本次处理。

### 8.4 设置分组字段与求和字段

在“分组字段”中选择一个或多个业务识别字段，例如“备件名称”或“货品编码”。分组字段至少选择一个。

“求和字段”是可选项，可以选择 0 个、1 个或多个数值字段，例如“数量”“发运方量”；完全不选择求和字段也是有效配置。同一个字段不能同时作为分组字段和求和字段。

**实际分组规则：用户选择的分组字段值相同，即归入同一组。** 其他非求和字段不再要求完全相同，而是汇集到结果行中：

- 用户选择的一个或多个分组字段组成分组键；只有这些字段参与分组判断。
- 求和字段不参与分组；选择了求和字段时，对同组记录逐项累加。
- 未选择任何求和字段时，不执行数值求和，所有非分组字段均作为普通字段处理。
- 其他非求和且非分组字段，将组内非空的不同值去重后，以换行符写入同一个单元格。
- 因此，同一备件名称下的多个件号会显示在“件号”单元格中，每个件号独占一行；同一组的仓库、客户等其他字段也会按不同值逐行汇集。
- 来源追溯字段不参与分组，也不参与求和。若业务字段已占用“来源文件”，系统使用“来源文件_追溯”；仍重名时追加序号，保留全部业务字段。

例如，字段为“备件名称、件号、收货方、发运方式、数量”，分组字段选择“备件名称”，求和字段选择“数量”时，同一备件名称的记录归为一行；件号、收货方、发运方式分别将组内不同值去重后换行汇集，数量累加。不同备件名称仍分开保留。若清空求和字段选择，则数量也不累加，而是将组内不同数量值去重后换行汇集。
### 8.5 求和字段数值规则

| 原始值 | 处理方式 |
| --- | --- |
| 空白单元格、空字符串 | 按 0 计算 |
| `30`、`30.5`、`-8` | 正常求和 |
| 文本数字 `"30"` | 转换为数值 30 |
| 千位分隔符 `"1,200"` | 转换为数值 1200 |
| `30件`、`待确认`、`abc` | 非数字异常，暂停整个任务 |

程序不会从“30件”中提取 30，也不会把非数字内容直接按 0 处理。若所有重复记录的求和字段均为空白，汇总结果为 0。数值计算采用 JavaScript 浮点数，涉及严格财务精度时应另行核验。

### 8.6 异常报告

发现非数字求和内容后，程序会完成异常位置收集，但不生成正式合并结果。异常报告包含：

- 来源 Excel 文件名；
- 工作表名称；
- 原始行号；
- 异常字段名称；
- 原始单元格内容。

页面展示前 100 条异常，点击“导出异常报告 Excel”可导出完整异常列表。修改原始 Excel 后，重新选择来源并执行合并。

### 8.7 合并前预览与结果保存

全量检查完成后，页面显示来源文件数、参与 Sheet 数、纳入处理的原始数据行数、合并后行数、减少的重复行数、标准字段、分组字段和求和字段，并展示前 50 条合并结果。求和字段统计会显示实际选择数量；未选择时显示“未选择”，表示本次不进行数值求和。确认无误后点击“确认生成结果表”。

结果首先写入 TableKit 工作区，来源表保持不变；可继续在数据预览中筛选、编辑、透视或导出。点击“导出合并结果 Excel”生成新的 XLSX，自动设置筛选和列宽。

文件保存位置说明：

- 使用浏览器目录授权选择文件夹时，结果保存到首个来源文件所在目录；如果目标文件名已存在，自动增加序号。
- 手动多选文件时，浏览器不会向网页提供来源文件所在目录，因此通过另存为选择保存位置。若另存为选择了与来源文件同名的文件，程序会阻止写入，避免覆盖来源。刷新或重新打开 HTML 后，工作区合并结果可从浏览器本地数据库恢复，但文件夹授权句柄不会持久化，需要重新通过另存为选择位置。
- 不支持保存对话框时，使用浏览器下载机制；重名文件的处理方式由浏览器下载设置决定。

当前内置 SheetJS 社区版支持自动筛选和列宽设置，但不支持可靠写入冻结窗格，因此导出的工作簿暂不保证冻结首行。

### 8.8 样例验证

项目 `test/` 目录提供字段合并样例文件，可按以下步骤验证：另有 `字段合并_非首行表头样例.xlsx`，用于验证第 3 行表头的识别。

1. 选择“字段合并样例_A.xlsx”和“字段合并样例_B.xlsx”，读取工作表。
2. 将 B 文件的“零件编号”映射到“货品编码”，将“发货数量”映射到“数量”。
3. 选择“备件名称”为分组字段，选择“数量”为求和字段；检查件号是否在同一单元格中按行换行显示。
4. 清空“求和字段”后重新预览，确认数量不再累加，而是按组内不同值换行汇集；未选择求和字段时，文本和数字内容均不执行数值校验。
5. 执行预览，核对同一备件名称被汇总为一行，件号、收货方、发运方式的不同值分别换行汇集，数量和方量按所选字段累加。
6. 再使用“字段合并异常样例.xlsx”，将“数量”设为求和字段，应得到非数字异常报告，且不能生成正式合并结果。

### 8.9 使用边界

公式读取可选择“读取上次保存的计算值”或“读取公式文本”。默认读取缓存值；若源文件公式未在 Excel 中重算并保存，缺少缓存的公式可能按空值读取，建议先在 Excel 中重算、保存。Excel 工作簿由浏览器内存解析，单次只逐个打开来源文件，但超大 Excel 文件仍受设备内存限制；汇总中间结果写入 IndexedDB，最终 XLSX 封装也需要内存。单个工作表最多 1,000 个字段，Excel 导出最多 1,048,575 行数据（另含表头），单元格文本最多 32,767 字符。大体量任务建议先拆分工作簿并分批处理。

## 九、导出结果

### 9.1 选择正确的导出入口

| 入口 | 导出范围 |
| --- | --- |
| 导出筛选结果 | 当前表中满足筛选条件的全部记录，采用当前显示字段和排序配置 |
| 导出当前完整表 | 当前表的全部字段与记录，不受当前筛选、显示字段及排序配置限制 |
| 导出去重结果 | 结果提示所指向的去重表的全部字段与记录 |
| 导出透视结果 | 结果提示所指向的透视表的全部字段与记录 |

所有入口都不限于当前预览页。去重与透视入口通常指向最近生成或恢复的对应结果；需要导出较早的结果时，在表单列表中选择该表，再使用“导出当前完整表”。

### 9.2 格式与保存位置

1. 在导出按钮旁选择格式。
2. 点击导出按钮。
3. 在保存对话框中选择目录并确认文件名。
4. 等待“已保存”提示后，再打开结果文件核对。

取消保存对话框会取消本次导出，工作区数据仍保留。不支持该对话框时，页面提供下载链接；点击后，保存位置由浏览器下载设置决定。保存对话框报权限错误时，可使用桌面 Chrome / Edge 普通窗口重新尝试。

| 格式 | 适用场景与说明 |
| --- | --- |
| XLSX | 常规 Excel 交付；保留文本值及数值汇总结果的类型，不还原源表格式 |
| CSV | 大体量明细、跨系统交换；UTF-8 编码，逗号分隔 |
| TSV | 制表符分隔的数据交换；UTF-8 编码 |
| JSON | 程序接口及后续处理；对象数组，每个对象对应一条记录 |

CSV、TSV 附带 BOM，默认启用“防止公式执行”。该选项会对可能被表格软件识别为公式的文本添加保护前缀；它不修改工作区原始数据。XLSX 字符串按文本写入，JSON 保留原始值，不采用该前缀处理。

CSV、TSV 本身不声明单元格类型。若用 Excel 直接打开后件号前导零消失，应通过 Excel 的文本导入功能指定文本列，或选择 XLSX 导出。

## 十、撤销与缓存清理

### 10.1 撤销操作

各位置的“撤销”按钮共用一份操作记录，按钮名称显示即将撤销的操作。按最近操作在先的顺序依次撤销，不是只撤销当前模块的操作。

| 操作 | 撤销效果 |
| --- | --- |
| 导入 | 移除本次导入创建的表；一次导入多表时整批撤销 |
| 删除、编辑、新增 | 移除本次生成的结果表，回到操作前来源；批量清洗整批撤销 |
| 去重、透视 | 移除本次生成的结果表，恢复此前工作区视图；来源表保留 |
| 应用筛选、排序、显示字段 | 恢复上一次应用的视图设置 |
| 清空筛选与排序 | 恢复清空前的条件与排序设置 |

仅保留本次打开页面期间最近 30 步记录。刷新或关闭页面后，已缓存的数据可能仍在，但撤销记录会清空。不支持重做；尚未点击“应用并预览”的逐项字段编辑不单独记录。导出到电脑上的文件不会被撤销删除。

### 10.2 清理浏览器缓存

先导出需要保留的结果，再点击侧栏“清理浏览器缓存”，核对确认提示后执行“清空全部数据”。完成后，统计卡片、工作区和预览区应恢复为空。

此操作清除当前工作台的导入表、结果表、临时计算数据及撤销记录，**不可撤销**。电脑上的源文件与已导出文件不受影响。处理任务进行中不能清理，应等待任务结束。

## 十二、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 生成新表后，文件夹内找不到文件 | 新表在浏览器工作区中；使用相应导出入口保存到电脑 |
| 导出只想保留部分字段，却得到全部字段 | 使用了完整表或结果表导出；应选择“导出筛选结果” |
| 修改筛选后预览没有变化 | 点击“应用并预览”；确认操作的是正确来源表 |
| 排序后去重仍未保留数量最大的行 | 首行/末行按原始导入顺序判断，排序不改变去重保留顺序；当前不直接提供“按最大值保留”规则 |
| 中文乱码、编码错误或全部内容挤在一列 | 检查文件编码与分隔符；重新选择正确参数导入 |
| Excel 公式结果为空 | 源文件没有已保存计算值；先计算并保存源文件，或读取公式文本 |
| 日期排序不符合时间先后 | 日期文本格式不统一；先统一日期格式后再排序 |
| 透视没有预期字段 | 检查来源表中的同名公共字段，确认名称与业务含义一致 |
| 透视数量偏大 | 检查重复记录，或是否同时选择了原始表及其处理结果 |
| 刷新后无法撤销 | 撤销记录仅在当前页面会话有效；需重新操作或重新导入 |
| 文件打开位置改变后，原有数据不见了 | 缓存与浏览器配置及文件地址有关；从源文件重新导入 |
| 处理缓慢或存储空间不足 | 大文件优先使用 CSV；减少字段、透视列组合及来源表，导出必要结果后清理缓存 |
| 清理提示仍有写入 | 关闭其他工作台标签页，等待任务完成后重试 |

## 十三、使用边界

| 项目 | 当前限制 |
| --- | --- |
| 单表导入字段 | 最多 1,000 个 |
| 透视来源 | 每次最多 50 张表、1 个汇总指标 |
| 列透视组合 | 最多 100 种 |
| CSV / TSV / JSON 导出 | 单次最多 2.5 亿字符 |
| XLSX 导出 | 最多 1,048,575 行明细，另含 1 行表头；单元格文本最多 32,767 字符 |
| 撤销记录 | 当前页面会话最近 30 步 |

Excel 导入与 XLSX 封装需要内存，CSV 分块处理也受设备资源和浏览器存储配额限制。数值汇总使用浮点数，不能替代要求严格十进制精度的财务结算工具。重要结果应导出归档，不以浏览器缓存作为唯一保存位置。
