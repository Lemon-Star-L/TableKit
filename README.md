# TableKit｜表格数据处理工作台

TableKit 是一款本地运行的表格数据处理工具，面向业务明细整理、重复记录清洗和多表汇总分析，提供从文件导入到结果导出的完整操作流程。

项目采用 **Python 构建、浏览器运行** 的方式，将页面、处理逻辑与 Excel 解析库封装为独立 HTML。生成后无需持续运行 Python，无需部署后台服务，可离线使用。业务数据在当前浏览器中处理，源文件不被修改。

详细操作步骤、样例验证与常见问题见 [中文操作手册](help/操作手册.md)。

## 核心功能

| 模块 | 功能 |
| --- | --- |
| 文件导入 | 支持 XLSX、XLSM、XLS、XLSB、CSV、TSV、TXT；支持工作表选择、表头行、编码及分隔符配置 |
| 数据整理 | 分页预览、显示字段选择、多条件筛选、文本及数值复合排序 |
| 重复处理 | 按指定字段或排除字段判重，保留首行、末行，或删除重复组仅保留唯一记录 |
| 透视分析 | 单表与多表汇总；配置行、列、值字段，支持求和、平均值、极值、行数及非空/去重计数 |
| 结果导出 | 支持 CSV、Excel（XLSX）、TSV、JSON；提供筛选结果、当前完整表、去重结果和透视结果四类导出入口 |
| 操作撤销 | 按操作顺序撤销本次页面会话最近 30 步导入、去重、透视、应用视图及清空筛选操作 |

## 快速开始

### 直接使用

使用桌面版 Chrome 或 Edge 普通窗口打开：

```text
output/表格数据处理工作台.html
```

此方式无需安装 Python。HTML 可单独复制到其他电脑使用，但不会携带浏览器中已导入的业务数据。

### 重新构建

项目环境要求为 **Python 3.13+**，构建程序仅使用 Python 标准库，无需安装第三方 Python 依赖。在项目根目录执行：

```bash
python main.py
```

也可使用 `uv run main.py`。程序默认生成并打开 `output/表格数据处理工作台.html`。

```bash
# 仅生成文件，不自动打开浏览器
python main.py --no-browser

# 指定生成目录
python main.py --output D:/TableKit_Output
```

## 使用流程

1. **导入文件：** 选择或拖入本地文件，读取工作表，确认导入设置后载入数据。
2. **整理数据：** 选择当前表，配置显示字段、筛选条件与排序规则，点击“应用并预览”。
3. **生成结果：** 执行去重或透视，结果以新表保存在工作区，可继续整理与分析。
4. **保存文件：** 在相应导出入口选择格式，点击导出并选择文件名及保存位置。不支持保存对话框的浏览器会提供下载链接，位置由浏览器下载设置决定。
5. **撤销操作：** 点击“撤销”恢复上一操作。刷新或关闭页面会清空撤销记录；清理全部缓存不可撤销，已导出的文件不受撤销影响。

导出不限于当前预览页。“筛选结果”遵循当前筛选、排序及字段设置；“当前完整表”“去重结果”“透视结果”导出对应表的全部字段与记录。

## 数据处理口径

- **筛选与排序：** 多个条件按 AND 关系执行，排序优先级自上而下；数值模式支持规范的千位分隔符，无效数值排序置末。
- **重复记录：** 首行、末行按原始导入顺序确定，不受当前排序影响。判重不自动去空格、忽略大小写或将 `01` 与 `1` 视为相同。
- **多表透视：** 按同名公共字段纵向追加数据，不执行主键关联；重复记录仍参与汇总。结果为计算时的快照，修改配置后需重新生成。
- **字段与公式：** 导入值主要按文本保留，文本件号的前导零予以保留；不重建 Excel 数字补零格式、样式、宏或合并结构。公式读取已保存计算值或公式文本，不重新计算。
- **导出格式：** CSV、TSV 使用 UTF-8 编码并附带 BOM；JSON 为对象数组；XLSX 字符串按文本写入，数值汇总结果按数值写入。CSV、TSV 默认启用公式防护，可能在公式样式文本前添加单引号。

## 运行边界

CSV 分块读取，排序与分组使用浏览器本地数据库；Excel 导入与 XLSX 导出需要内存。实际处理容量取决于文件结构、计算复杂度、设备内存及浏览器存储配额，大体量数据优先使用 CSV 或 TSV。

| 项目 | 当前边界 |
| --- | --- |
| 导入字段 | 每表最多 1,000 个 |
| 透视来源 | 每次最多 50 张表、1 个汇总指标 |
| 列透视 | 最多 100 种列字段组合 |
| 文本格式导出 | CSV、TSV、JSON 单次最多 2.5 亿字符 |
| XLSX 导出 | 单表最多 1,048,575 行数据，另含一行表头；单元格文本最多 32,767 字符 |
| 数值精度 | 使用浮点数，不作为严格十进制财务结算工具 |

浏览器缓存不是业务归档。清理浏览器数据、更换浏览器或移动 HTML 后可能需要重新导入，重要结果应及时导出。处理期间请勿关闭页面，也应避免在多个标签页同时操作同一份工作区数据。
