# TableKit｜表格数据处理工作台

TableKit 面向业务明细整理、重复记录清洗和多表汇总，采用 Python 构建、浏览器运行的方式，将页面与 Excel 解析组件封装为可独立使用的 HTML。生成后无需后台服务，可离线使用；业务数据由浏览器本地处理，原始文件不被修改。

**版本：1.2.3** · 维护者：YiLong Li  &  BaoTong Liu

[中文操作手册](help/操作手册.md) 

## 主要功能

| 模块 | 能力 |
| --- | --- |
| 文件导入 | Excel、CSV、TSV、TXT；工作表选择、表头行、编码及分隔符设置 |
| 数据整理 | 分页预览、字段选择、AND/OR 筛选、复合排序、空值及计算错误筛选 |
| 数据修改 | 按条件删除、勾选行删除、编辑、新增行及多表批量清洗；生成新表保留来源 |
| 重复处理 | 指定或排除字段判重；保留首行、末行或仅保留唯一记录 |
| 透视分析 | 单表和多表汇总，支持求和、均值、极值、记录数及非空/去重计数 |
| 字段合并 | 多文件、多 Sheet、文件夹导入；手动映射、缺字段处理、自选分组和可选多字段求和、其他字段多值换行汇集 |
| 结果保存 | CSV、XLSX、TSV、JSON；筛选结果、完整表及各处理结果独立导出 |
| 操作恢复 | 当前页面会话最近 30 步撤销；工作区缓存清理 |

## 快速开始

直接使用桌面版 Chrome 或 Edge 普通窗口打开 `output/表格数据处理工作台.html`，无需安装 Python。单独复制该 HTML 即可分发工具，已导入的业务数据不会随文件转移。

修改模板或重新构建时，使用 Python 3.13+，在项目根目录执行：

```bash
python main.py
# 仅生成，不自动打开浏览器
python main.py --no-browser
# 指定生成目录
python main.py --output D:/TableKit_Output
```

也可执行 `uv run main.py`。常规构建只用 Python 标准库，离线 Excel 读写组件已放在 assets 中。

## 使用流程

1. 选择文件，读取工作表并确认导入设置。
2. 选择当前表，配置筛选、排序及显示字段，应用并核对记录范围。
3. 执行删除、编辑、去重、透视或字段合并，检查结果表和处理统计。
4. 选择导出格式与保存位置，将结果保存到电脑。

“生成新表”只写入浏览器工作区，不会自动生成磁盘文件。筛选结果导出遵循筛选、排序与字段设置；完整表和各结果表导出不限预览页。支持保存对话框时可选位置，否则按浏览器下载设置保存。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `main.py` | 唯一 Python 入口：构建 HTML、可选 Excel 清洗 |
| `pyproject.toml` | 版本、Python 要求及可选依赖 |
| `assets/` | HTML 模板、Excel 读写库、图标和第三方许可证 |
| `output/` | 已构建、可独立运行的 HTML |
| `help/` | 操作手册、样例验收及版本对比说明 |
| `test/` | 模拟数据、清洗规则及预期结果 |

业务文件可从任意本地位置选择，无需固定 input 目录。output 不存在时由程序创建。浏览器缓存与导出文件的位置不等同于项目目录。

## 处理口径

- 筛选支持 AND（全部满足）与 OR（任意满足）；排序按配置自上而下执行。0 不属于空值。
- 计算错误按导入值匹配错误标记；不重新计算 Excel 公式。应先在 Excel 中重算并保存。空结果条件也会匹配普通空单元格，无法仅凭空值确定其公式来源。
- 去重的首行、末行按原始导入顺序确定，当前排序不改变保留顺序；不自动去空格或统一大小写。
- 多表透视按同名公共字段纵向追加，不进行主键关联；重复记录仍参与汇总。
- 字段合并只按所选分组字段归组。求和字段可选零个或多个；其他字段去除组内重复的非空值后以换行汇集。所选求和字段遇到非数字内容会生成异常报告并停止正式结果生成。
- 网页以值为中心，不保留源工作簿样式、宏和合并结构；文本编码前导零可保留。来源追溯列自动避让同名业务字段。
- 撤销仅在当前页面会话有效。刷新后撤销记录清空；清理全部缓存不可撤销，已导出文件不受影响。

## 可选 Excel 清洗

需要保留普通单元格格式时，可使用同一入口的清洗模式：

```bash
python -m pip install "openpyxl>=3.1.5,<4"
python main.py --clean-excel "业务.xlsx" --rules "test/清洗规则示例.json"
# uv 用户也可使用
uv run --extra excel main.py --clean-excel "业务.xlsx" --rules "test/清洗规则示例.json"
```

支持 XLSX/XLSM，第一行为表头，按规则删除匹配行。缺字段的表保留并报告；输出另存为带“清洗结果”后缀的新文件及 JSON 报告，重名自动编号。此模式不计算公式，不保证维护复杂合并结构、图表及跨行公式依赖，具体规则见操作手册。

## 运行边界

| 项目 | 限制 |
| --- | --- |
| 导入字段 | 每表最多 1,000 个 |
| 透视来源及指标 | 每次最多 50 张表、1 个指标 |
| 透视列组合 | 最多 100 种 |
| CSV/TSV/JSON 导出 | 单次最多 2.5 亿字符 |
| XLSX 导出 | 每表最多 1,048,575 行数据；单元格文本最多 32,767 字符 |
| 数值计算 | 浮点计算，不作为严格十进制财务结算工具 |

CSV 分块读取，排序和分组使用浏览器本地数据库；Excel 解析及 XLSX 封装仍占用内存。实际容量取决于数据结构、设备与浏览器配额，不承诺任意规模文件均能完成。工作区建议只开一个标签页，重要结果及时导出。

第三方 Excel 组件许可见 `assets/SheetJS-LICENSE.txt`。
