01　选择数据来源

尚未选择文件

先设置默认表头行再选文件，或点击“应用到全部 Sheet”；也可以在下方来源清单中逐个修改每个 Sheet 的表头行。表头行按 Excel 实际行号填写（例如第 3 行填 3）。

▧等待选择 Excel 文件

使用说明与数据口径

撤销支持本次打开页面期间最近 30 步导入、去重、透视、应用筛选/排序/显示字段以及清空筛选操作，按操作顺序依次恢复。刷新或关闭页面会清空撤销记录。清理全部缓存不可撤销；已经导出到电脑的文件不受撤销影响。

此 HTML 可独立离线使用，不需要 Python 服务。选择文件后点击读取表单及导入；字段与表单均可直接勾选，无需按住 Ctrl。缓存位置：；导出位置：。

通过网页选择电脑上任意位置的数据文件，无需放入指定文件夹。缓存与浏览器、用户配置及文件地址有关，移动 HTML 或换浏览器后可能需要重新导入。清理浏览器数据或使用无痕窗口会影响持久保存，处理结果请及时导出。

字段默认按文本保存；数值汇总为浮点数。Excel 公式不重算，仅读取已保存计算值或公式文本；日期统一为 ISO 格式。多表透视按同名公共字段纵向追加，并非关联连接，重复记录仍计入。结果为新表，源文件不修改。

CSV 支持分块读取，排序和分组使用本地数据库；超大 Excel 解析、复杂计算及导出仍受内存和磁盘限制。CSV / TSV / JSON 单次导出最多 2.5 亿字符。Excel 导出在内存中封装，单表最多 1,048,575 行数据（另含表头）；大数据建议使用 CSV / TSV。JSON 导出为对象数组，保留原始值；公式防护选项用于 CSV / TSV，Excel 字符串按文本写入。不要在任务运行中关闭页面；中断任务可用“清理浏览器缓存”释放残留空间。
